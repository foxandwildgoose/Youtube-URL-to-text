# MP4 TO TEXT 구현·검증 보고서

검증일: 2026-10-06. 기존 YouTube 자막과 Upload File 음성 전사에 독립적인 세 번째 시각 추출 모드를 추가했다. 새 유료 모델 호출이나 배포는 실행하지 않았다.

## 구현된 동작

- 원본 MP4는 로컬에 남는다. 오디오 없는 MP4도 처리하며, 시각 모드에서 음성 추출·전사·요약 API를 호출하지 않는다.
- 네 모서리 ROI와 시점별 키프레임, 원본/원근 보정 미리보기, 실제 영상 타임스탬프 기반 프레임 캡처를 제공한다. 네이티브 디코딩을 우선하고 영상 스트림만 읽는 제한된 FFmpeg 대안을 지원한다.
- 로컬 비교는 등장 순서, A→B→A 재등장, 추가/사라지는 애니메이션, 짧고 불확실한 후보를 보존한다. 경계 오차 범위와 검은 화면·불확실 구간을 기록하고, 흔들림/후보 폭증 시 검토를 위해 멈춘다. 후보 삽입·제외, 경계 수정, 대체 이미지, 논리 그룹을 수동 검토할 수 있다.
- 원본 해상도의 무손실 PNG를 필요하면 겹치는 크롭으로 분할한다. 브라우저→서버 전체 multipart 요청은 3,500,000바이트 이하이며, 승인된 이미지 하나씩만 전송한다.
- 서버 전용 Responses 어댑터가 개인 접근 코드, 동일 출처, 모델 허용 목록, 이미지 서명/크기, 엄격한 메타데이터와 구조화 응답을 검증한다. 삽입된 명령/URL은 자료로 취급하고 도구를 제공하지 않는다.
- USD 사전 승인, 기본 $5 작업 예산, 요청 제한, 제한된 rate-limit 재시도, 사용량 기반 비용과 미확정 비용 예약을 구현했다. 전송 의도와 각 결과를 저장하므로, 응답 유실 후 유료 요청을 자동 반복하지 않는다.
- 원문·수정본·이전 시도를 별도로 보존한다. 재시도 결과는 비교 후 선택하며, 기존 수정본을 자동 덮어쓰지 않는다. 이미지 SHA-256와 크롭/변환/모델/설정/프롬프트·스키마 버전으로만 결과를 재사용한다.
- IndexedDB v2의 별도 이미지 저장소와 소스 기반 잠금/임대를 추가했다. 기존 기록과 v1 백업을 유지하며, 이미지가 빠진 텍스트 백업은 원본 재선택 후 로컬 복구할 수 있다. 픽셀이 다르면 과거 유료 결과를 다른 이미지에 재사용하지 않는다.
- 시간순 후보 갤러리, 이미지 확대, 원문/수정본 비교, TXT·Markdown·JSON과 Windows BOM을 제공한다. 세 모드 키보드 탐색, 기록 검색/재열기, 밝은/어두운 테마를 유지한다.

기능 브라우저 검사는 유료 API와 외부 글꼴/브랜딩만 가로채며 실제 영상/이미지/저장은 실행한다. 모의 인식 텍스트는 정확도 증거가 아니다. 기본 외부 리소스 검사의 TLS 검증을 끄지 않았다. 이전 자동 승인 검토가 Chromium 신뢰 저장소에 프록시 CA를 추가하는 조치를 거절했으며, 해당 변경을 재시도하거나 우회하지 않았다.

16초 1280×720 H.264 자료에는 한국어/영어, 코드, 표/빈 셀, 각주, 제목이 같은 숫자 변경, 추가/교체 애니메이션, 재등장, 텍스트 없는 도형, 검은 화면이 있다. `ffprobe`로 영상 스트림만 존재함을 확인했다. 별도 실제 브라우저 확인에서 FFmpeg 영상 전용 대안의 3.1초 캡처는 `ffmpeg-pts`, 불확실성 0.04초, 768×432 프레임을 반환했다. 이를 전체 코덱·대용량 호환성으로 확대 해석하지 않는다.

## 설정과 사용

서버에 `OPENAI_API_KEY`와 무작위 24자 이상 `SLIDES_ACCESS_TOKEN`을 설정한다. 전용 토큰이 비어 있으면 기존 `TRANSCRIPTION_ACCESS_TOKEN`을 사용한다. 실제 값은 소스/백업에 넣지 않는다. 현재 환경에는 API 키가 없어 유료 모델 호출은 실행하지 않았다. 클라우드 온보딩 초안의 재사용 시작 안내와 필요한 환경 변수 이름은 갱신했으며, 환경 발행은 실행하지 않았다.

기본값은 Standard `gpt-6.1-sol`/`low`, Economy `gpt-6-luna`/`none`, 이미지 `auto`, 출력 제한 4096, 제공자 제한 시간 45초다. 공식 문서에서 모델별 이미지 토큰 수식은 확인되지 않아 크기 기반 조정 가능한 휴리스틱을 사용한다. `original` 상세도는 활성화하지 않았다. 자세한 설정·공식 출처·보존 정책은 [slides.md](slides.md)를 참조한다.

**MP4 TO TEXT → 파일 선택 → 재생 위치 미리보기 캡처 → ROI 적용 → 로컬 후보 탐색 → 후보 검토 → 개인 코드/비용 승인 → 텍스트 추출 → 원문과 수정본 검토 → 내보내기** 순서다. 처음에는 1–3개 후보만 승인해 실제 인식 품질을 확인한다. 기록을 다시 열었을 때 재생/추가 로컬 작업은 원본을 재선택한다. 빠진 이미지는 **Regenerate missing saved evidence**로 복구한다.

## 비용 예와 남은 검증

가정: Sol 96회, 회당 총 입력 3,000토큰·청구 출력 1,000토큰. 공식 Standard 단가 $2/M·$10/M이면 `96 × (3000 × 2/M + 1000 × 10/M) = $1.536`, 계획 여유 25%를 더하면 **$1.92**다. 25%는 OpenAI 추가 요금이 아니며, 실제 토큰·호출 수·인식 정확도를 보장하지 않는다. reasoning이 출력 합계에 포함되면 다시 더하지 않는다. 160회·입력 7,000·출력 1,500의 가정은 여유 포함 $5.80이므로 기본 $5 예산에서 호출 전 멈추는 테스트가 통과했다.

- **실제 Windows/GoPro 1GB·40분 자료: NOT RUN.** 실제 녹화가 제공되지 않았다.
- **실제 Sol/Luna 인식 평가·유료 파일럿: NOT RUN.** 모의 응답으로 정확도나 두 모델의 동등한 성능을 주장하지 않는다.
- **배포 및 실제 Vercel 운영 환경 검사: NOT RUN.** 로컬 빌드 미리보기 검사만 수행했다.

[slides-validation.md](slides-validation.md)에 실제 장비·코덱·시간·메모리·후보 누락·전송량·토큰·비용·재개·수동 오탈자 평가 절차를 기록했다. 아주 짧은 표시, 흔들림/가림, 작은 흐린 글자, 근사 원근 보정과 경계 탐지, 브라우저 메모리/저장소/열린 탭 제약은 남아 있다. 잠금/예산은 브라우저 운영 가드이며 제공자 청구의 전역 중복 방지나 계정 예산이 아니다. `store:false`도 무보존을 뜻하지 않는다.
